# MathTrain

 I made this fun math game in HTML, CSS and Javascript!

**Live site:** https://mathtrain.vercel.app

---

## Stack

- HTML
- CSS
- Javascript

---

## About

In this game, you recieve a 2 number math problem with a random operator. Your goal is to guess the correct answer as many times as possible and reach a high streak! Watch out though! One mistake and your streak is back to 0!

## Features

- Addition
- Subtraction
- Multiplication
- Streaks
- High-score
